## 停止 MySQL 服务

先从系统设置的 MySQL 面板停止服务，确认没有其他应用正在使用数据库。

![MySQL 服务状态面板](/static/images/reset-mac-mysql-password/mysql-server-status.png)

本文的 DMG 安装可以使用以下命令；必要时按系统权限要求使用 `sudo`。

```shell
/usr/local/mysql/support-files/mysql.server stop
```

![MySQL 服务停止结果](/static/images/reset-mac-mysql-password/mysql-stop-success.png)

![确认 MySQL 已停止](/static/images/reset-mac-mysql-password/mysql-stop-status.png)

## 临时跳过权限校验

<Callout type="sick">
跳过权限校验会降低数据库安全性。仅在受控的本地环境中短暂使用，并关闭网络监听；完成后必须结束这个临时实例，恢复正常服务。不要将这种启动方式作为日常配置。
</Callout>

```shell
cd /usr/local/mysql/bin
sudo ./mysqld_safe --skip-grant-tables --skip-networking
```

保持这个终端打开。另开一个终端，通过本地 Unix socket 登录：

```shell
cd /usr/local/mysql/bin
./mysql -u root
```

## 修改 root 密码

在 MySQL 客户端中执行：

```sql
FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Replace_With_A_Strong_Password_123!';
```

示例密码只是占位，请替换为自己生成的强密码，并安全保存。

如果出现 `ERROR 1290`，先确认已经执行 `FLUSH PRIVILEGES`。如果出现 `ERROR 1819`，新密码未满足当前策略，应选择符合要求的密码，**不要为了方便而降低全局密码长度或强度要求**。

## 恢复正常服务

先在当前 MySQL 客户端停止临时实例：

```sql
SHUTDOWN;
```

再按正常方式启动服务：

```shell
sudo /usr/local/mysql/support-files/mysql.server start
mysql -u root -p
```

按提示输入新密码，确认可以登录，并确认服务不再以 `--skip-grant-tables` 启动。

## 其他服务操作

```shell
# 停止服务
sudo /usr/local/mysql/support-files/mysql.server stop

# 重启服务
sudo /usr/local/mysql/support-files/mysql.server restart
```

无法停止时，先检查错误日志与实际进程，不要直接对未知 PID 发送结束信号。

```shell
ps -ef | grep mysqld
```
