## 查看系统信息

先确认 macOS 版本和处理器架构。本文使用 macOS 12.6、Intel Core i9。

![macOS 版本与 Intel 处理器信息](/static/images/mac-install-mysql/my-os-version.png)

## 下载

打开 [MySQL 官方下载页面](https://dev.mysql.com/downloads/mysql/)，选择与系统版本和架构相符的安装包。

![MySQL 的 macOS 安装包列表](/static/images/mac-install-mysql/mysql-download-list.png)

本文选择 **macOS 12 (x86, 64-bit), DMG Archive**，点击 **Download**。

![MySQL 下载确认页面](/static/images/mac-install-mysql/mysql-download-confirm.png)

点击 **No thanks, just start my download**，即可直接下载。

## 安装

1. 双击 DMG 文件，打开安装器。

   ![打开 MySQL DMG 安装器](/static/images/mac-install-mysql/mysql-dmg-install.png)

2. 允许安装。

   ![macOS 的安装确认提示](/static/images/mac-install-mysql/mysql-install-warning.png)

3. 继续安装。

   ![MySQL 安装器的欢迎页面](/static/images/mac-install-mysql/mysql-install-01.png)

4. 按提示输入系统密码。

   ![MySQL 安装过程中的系统授权](/static/images/mac-install-mysql/mysql-install-02.png)

5. 选择 **Use Strong Password Encryption**。

   ![MySQL 的密码加密方式设置](/static/images/mac-install-mysql/mysql-install-03.png)

6. 为 `root` 用户设置符合密码策略的强密码，并妥善保存。

   ![MySQL root 密码设置](/static/images/mac-install-mysql/mysql-install-04.png)

7. 按安装器要求再次确认系统授权。

   ![确认 MySQL 安装授权](/static/images/mac-install-mysql/mysql-install-05.png)

8. 安装完成。

   ![MySQL 安装完成页面](/static/images/mac-install-mysql/mysql-install-06.png)

## 修改 PATH

为了直接在终端使用 `mysql` 命令，将 MySQL 的 `bin` 目录加入 `PATH`。以下路径对应本文的 DMG 安装方式。

先在终端执行 `env`，查看当前环境变量。

![终端中的环境变量](/static/images/mac-install-mysql/mysql-cli-os-env.png)

1. 编辑 `.zshrc`：

   ```shell
   vi ~/.zshrc
   ```

   也可以使用 VS Code 等编辑器。将下面这一行加入文件：

   ```shell
   export PATH=$PATH:/usr/local/mysql/bin
   ```

2. 使配置生效：

   ```shell
   source ~/.zshrc
   ```

   再执行 `env`，确认 `PATH` 中包含 MySQL 的 `bin` 路径。

   ![加入 MySQL bin 目录后的 PATH](/static/images/mac-install-mysql/mysql-cli-os-path.png)

3. 验证命令行工具：

   ```shell
   mysql --version
   ```

   ![MySQL 命令行版本输出](/static/images/mac-install-mysql/mysql-cli-version.png)

4. 登录数据库：

   ```shell
   mysql -u root -p
   ```

   按提示输入安装时设置的密码，不要把密码直接写进命令历史。

   ![MySQL 命令行登录结果](/static/images/mac-install-mysql/mysql-cli-login.png)
