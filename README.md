## ⌨️ 安装&运行

使用 pnpm 安装运行，博客使用 Next.js App Router。

```shell
pnpm install
pnpm run dev
```

打开 `http://localhost:3000`

生产构建和质量检查：

```shell
pnpm check-types
pnpm check
pnpm build
```

环境变量文件 `.env` 是可选的。
