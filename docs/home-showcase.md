# 首页卡片展示对齐

日期：2026-10-13。基线 `c780b73`。以下为提交前验收记录；本轮没有新增依赖，未执行生产部署。

## 对照与修正

实际打开 New Material 首页，查看初始状态与 Shuffle 后的画面，并核对其公开展示代码。用户截图指出的是实际卡片堆叠和右侧纵向位置 / 进度提示。原实现只有一张图片、两个纯色伪元素，以及下方横向分页；图片切换时重新淡入，不能表达卡片前后关系。

本轮按本站的真实项目内容调整：

- 首屏改为图像优先，保留原首页 h1 文案但移到展示后的介绍区域，缩短标题在图片上方占据的空间。
- 以现有六个独立项目作为展示池，始终有三张真实封面分层排列，后两张露出约 45px 的底部区域（桌面）。不使用黑 / 灰背景假扮后续卡片。
- 统一为 3:2 图片比例、逐层缩放和向下偏移；删除旧的伪元素堆叠、图片淡入与横向分页。
- 右侧使用可拖动、可键盘操作的纵向滑块。它表示项目位置，不伪造视频播放进度；本站当前使用图片素材，未复制参考站的视频、品牌或内容。
- 下方采用两行项目说明和 Shuffle；随机选择不会重复当前项目，随机发现后提供重置入口。
- 使用已有 Motion 的卡片进退与层级过渡，不卸载整个展示区。快速操作可重新定向动画，退出卡片不参与键盘和辅助技术访问。
- 支持卡片左右滑动、左右方向键；滑块支持上下方向键、Home / End。没有拦截整页纵向滚动。
- 前卡片打开项目页中对应的项目位置；项目条目使用同一套锚点生成规则。

保留此前放大的圆角、品牌头像、右下菜单和 MDX 加载修复。无 JS 时三张封面与第一张项目链接仍可使用；减少动效偏好下立即完成切换。仅当前图层是可访问链接，背景卡片为 inert。
