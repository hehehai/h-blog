# 文案、内容与导航优化

日期：2026-10-13。本轮接续 [第一轮 UI 升级](ui-upgrade.md)。以下为提交前验收记录，生产部署不在本轮范围；没有添加依赖或测试框架。

## 导航与动效

再次查看 New Material 首页与详情，并核对其公开的交互实现。参考站没有传统的顶部横排菜单，左下角的 **More from context** 主要用于上下文探索，并不等同于常规的站点导航。

本站按个人博客的使用场景调整：

- 顶部只保留品牌与联系入口；滚动后显示当前页面 / 文章名称，可返回页首。
- 左下角圆形点阵提供“探索本站”：五个页面入口、GitHub / X 与主题切换。支持键盘打开、Esc / 点击外部关闭与焦点恢复。
- 页脚保留五个完整入口。禁用 JS 时，浮动入口改为跳到页脚导航，不把浏览页面的能力依赖于弹层。
- 补充链接文字滚动、点阵随滚动旋转、项目翻页与分页点、图片卡片的轻量滚动入场；没有强制自动播放。
- 尊重减少动效偏好；不支持 View Transitions 或滚动时间线时保留普通导航和可见内容。

## 文案与信息

- 个人信息集中到 `src/lib/config/author.ts`，首页与关于页使用同一份介绍和技术栈。减少空泛的能力承诺，区分正在探索的方向与实际经历。
- 检查全部 24 篇文章的标题、摘要、标签和正文结构。标题说明具体主题与范围，统一 Next.js、Node.js、Vue 3、TypeScript、Snabbdom、shadcn/ui 等名称；日期统一为 UTC 的 `YYYY-MM-DD`。
- 五篇译文明确原文来源及“翻译与整理”身份，说明第一人称来自原作者；摘要不再把 Dub 团队的经历写成本站经历。结构化数据同步记录原文来源与翻译者。
- 对早期框架、平台限制和部署方式增加版本说明，不将历史截图与 API 描述包装成当前规则。
- Vue 响应式笔记的 `effect` 和虚拟列表的滚动区间说明明确标记待补充；关于页的经历 / 复盘占位不包含虚构履历。

### 重点纠正

1. Unicode：区分 UTF-16 码元、码点和字素簇，修正无引号的 Emoji 示例，补充 `Intl.Segmenter`。
2. Promise：纠正 `Promise.all` 会取消其他任务的错误表述，明确 `any` 的 fulfilled 条件及超时不等于取消。
3. 密码：说明 bcrypt 是哈希与验证，不是可逆加解密；MySQL 重置不再建议降低全局密码强度，补充隔离网络与恢复正常权限校验的步骤。
4. Docker：修正命令笔误，区分命名卷与宿主路径，并纠正“已经配置数据卷但声称没有持久化”的矛盾。
5. Git：修正 `--mixed`、`--amend`、`-am` 的说明，移除建议直接删除整份 `known_hosts` 的不安全表述。
6. Fetch：将 Node.js 示例的 `agent` 改为 `dispatcher`，修正环境变量引用，并注明旧 SDK / runtime 边界。
7. Product Hunt：修正凌晨 12:01 AM 被译为中午的问题和明显的机翻词语。
8. Snabbdom：修正库名与 TypeScript 拼写，将 21 个 Notion 迁移链接改为有效的文章锚点或官方资料链接。

不是完整的技术栈升级或安全审计：没有实际执行 MySQL 重置、Docker 部署、OAuth 登录或云平台发布。历史教程中的其他代码、定价及外站规则仍需按对应版本逐项核对。

## 阅读格式

- 调整以 h3 开头的正文及跳级小节，正文从 h2 开始，子节使用 h3；改变标题文字时保留旧锚点。
- 代码块增加语言 / 终端标签、复制按钮、成功 / 失败反馈；复制的是完整代码文本，不包含工具栏文字。
- 行内代码、表格、提示框与折叠说明统一样式；中文标点使用中文字体字形。
- FAQ 改为原生 details / summary，现代浏览器渐进增强高度过渡，旧浏览器及无 JS 环境仍能展开、收起。
- 邮箱提供直接联系与复制两种操作；移动端为浮动导航预留页脚空间。

## 推送前的安全处理

GitHub Push Protection 检出了邮件 OTP 历史示例中的硬编码 Resend API Key。当前示例已改为服务端 `RESEND_API_KEY` 环境变量，并补充 `.env` 与部署配置说明；未绕过保护。移除当前版本不能消除历史提交或截图中的潜在暴露，如果该密钥真实可用，应撤销或轮换。历史清理需单独处理。
