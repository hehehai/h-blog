# UI 升级与验收记录

日期：2026-10-13。以下为提交前验收记录，生产部署不在本轮范围；未添加依赖或持久化测试框架。

## 视觉与交互

实际用 Chromium 查看了 [New Material](https://newmaterial.ai/) 首页及 `/stories/tempo-studio` 详情页，保留原始参考截图。采用其居中留白、黑白灰、圆角图片、叠层展示与窄正文的视觉逻辑，不复制品牌、图片或文案，也不将个人博客改成商业落地页。

- 全站：统一色彩 token、Geist / MiSans 字体、标题层级、间距、导航、页脚、链接与深浅色。补齐首页和照片导航。
- 首页：现有三个项目的叠层图片、手动循环切换、精简介绍与文章摘要；没有自动播放或伪造项目。
- 文章列表：标题 / 摘要 / 标签搜索、热门标签筛选、结果数和空结果提示。
- 详情：居中标题、日期、阅读时长、摘要、作者；720px 正文和适度加宽的单张图片；桌面固定目录、移动端默认折叠目录、当前章节与阅读进度。
- 项目：两列图片卡片，小屏单列；图片和操作链接可打开项目；统一项目简介并修正明显笔误。
- 照片：大图领头的网格、图片放大弹层、左右按钮 / 方向键切换、Esc 关闭和焦点恢复。真实照片、重试、限流、旧数据的服务逻辑保留。
- 动效：View Transitions 切页，旧浏览器退回 CSS 入场；图片轻微缩放、切换淡入；真实请求的顶栏加载状态、页面和 MDX 骨架。支持 `prefers-reduced-motion`，不隐藏等待 JS 揭示的正文。

内容占位仅出现在项目页的“项目手记 · 待补充”和照片集为空时的“照片集 · 待补充”，没有假履历或虚构案例。修正了 Radix asChild 文章误用字体优化摘要，以及两篇文章摘要的明显笔误；没有批量重写历史正文。

## 浏览器验收

最终生产构建使用 `vp preview`，在本地 Workers 运行时验证，临时 Playwright 脚本不进入仓库。

| 范围 | 结果 |
| --- | --- |
| 桌面 1440×1000 / 手机 390×844 | 五个主页面及全部 24 篇文章，58 次检查；均为 200，无全页溢出、损坏页面图片、未捕获异常或站内资源失败 |
| 禁用 JavaScript | 24 篇文章均有可见正文，不停留在骨架屏 |
| 320px | 五个主页面、代表文章及照片弹层无全页溢出 |
| 交互 | 21 项通过：项目循环、原生切页、筛选 / 搜索 / 清除、目录锚点 / 当前章节、进度、带锚点刷新、主题持久化、照片放大 / 切换 / 关闭 / 焦点恢复、404 返回、减少动效、键盘跳过导航、加载状态 / 清理 |
| 降级 | 临时禁用 `document.startViewTransition` 后客户端导航与正文正常；减少动效偏好下取消入场动画 |
| 加载 | 浏览器延迟真实 RPC 1800ms 后截图，检查骨架与顶栏状态及请求完成后的清理；不是生产服务变慢或伪造成功响应 |

生产回归发现带文章锚点刷新时路由可在水合阶段重新进入加载状态，导致新进度条与预渲染 HTML 不一致。已让进度条首次客户端渲染与服务端一致，再于挂载后响应加载状态；最终锚点刷新及重复刷新无水合异常。

保留 `src/server.tsx` 的 `allReady`、无限 `progressiveChunkSize`、超时与取消清理，以及按文章拆分的 MDX。没有改为全量客户端 MDX 打包。

**边界**：仅真实 Chromium 浏览器检查，不等于真实手机硬件、Safari / Firefox 或完整 WCAG 审计。没有重新验收全部嵌入式沙盒控件组合，也没有声称 Core Web Vitals 提升。完整滚动扫描仍收到 6 个第三方 CodeSandbox `/cdn-cgi/rum` 遥测 404，属于已有外部问题，未屏蔽；见 [沙盒遥测说明](sandpack-telemetry.md)。
