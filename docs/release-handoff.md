   braces 超过 100 层结构性嵌套被拒绝。
5. **人工验收有范围**：没有穷尽所有控件组合、浏览器、网络故障及第三方项目执行结果。

   都需后续维护，不能扩大为通配符。见 [依赖升级记录](dependency-upgrade.md)。

## 本地复核顺序

```sh
vp install --frozen-lockfile
# 首次检出先生成内容集合类型和路由树。
vp build
vp run check-types
vp run check
vp env exec pnpm peers check
vp env exec pnpm audit --prod
vp exec wrangler deploy --dry-run
```

如需检查完整审计，另行运行 `vp env exec pnpm audit`，不要把已知的非零退出码误记为通过。
使用只读审阅和独立干净副本，不要在当前有未提交改动的工作区中硬重置。

本地预览可在空闲端口启动：

```sh
vp preview --host 127.0.0.1 --port 4393 --strictPort
```

开发服务、生产预览串行启动，避免默认 inspector 自动选端口的竞争；HTTP 端口被占用时
选择其他端口，并同步修改检查地址，不要停止其他项目的进程。
